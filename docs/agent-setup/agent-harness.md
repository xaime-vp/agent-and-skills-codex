# Agent harness, issue routing and retirement plan

This workspace adds reusable GitHub admin, planner and researcher guidance for the base coding agent. Runtime profiles remain a separate Constant Integration implementation: [profile proposal #369](https://github.com/xaime-vp/constant-integration/pull/369). The proposed [CI label gate #370](https://github.com/xaime-vp/constant-integration/pull/370) is also separate; inspect merged workflows before treating it as active.

The intended flow is request → GitHub admin triage → optional research/planning → scoped implementation → tests/documentation → ready for review → ready-to-merge CI → completion assessment. Detailed contracts and compatibility retirement evidence follow in this PR.
